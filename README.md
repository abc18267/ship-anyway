# Ship Anyway

A one-tap tool for ADHD perfectionism: capped work sessions, forced shipping, a spiral interrupt, next-day follow-ups and weekly markers. Built for a medication-free plan; works alongside medication too.

Single static page, no build, no server. Data stays in your browser (localStorage). Voice commands use the browser's own speech recognition (Chrome, Edge, Safari); nothing leaves the device.

Open `index.html`, or the GitHub Pages copy once enabled.
